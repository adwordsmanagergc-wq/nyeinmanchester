Booking tips

  • Many parties release tickets in tiers, so the first release is the cheapest.
  • Check whether drinks are included or pay-as-you-go.
  • Most parties are 18+ (Albert's Schloss is 21+) with ID checks.
  • Note last entry times. Some venues stop letting people in at 10:30pm.
